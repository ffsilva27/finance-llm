# Relacionamento com banco que você não conhece

Se as informações estão erradas ou se seus dados foram usados sem sua autorização por terceiros para abertura de conta, entre em contato com o banco. Pode acontecer de o seu banco não ser registrado na base de dados do Banco Central (BC), mas fazer parte de um grupo econômico ou ter vínculo com alguma instituição registrada, que fica responsável por encaminhar dados ao BC. Estamos trabalhando para diferenciar esses vínculos nos relatórios.
