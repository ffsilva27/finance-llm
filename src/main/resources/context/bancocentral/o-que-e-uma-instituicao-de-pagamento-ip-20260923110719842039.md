# O que é uma Instituição de Pagamento (IP)?

É uma pessoa jurídica não financeira que executa os serviços de pagamento no âmbito de arranjos de pagamento e que é responsável pelo relacionamento com os usuários finais do serviço de pagamento. Acesse aqui para saber mais sobre arranjo de pagamento.
