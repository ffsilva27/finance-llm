# O que é o Pix

O Pix é uma forma de fazer pagamentos ou transferências, em qualquer hora do dia e da semana, de maneira instantânea, prática e segura. Além de fazer transações imediatas, com o Pix você também pode pagar contas com data de vencimento, agendar transações e até sacar dinheiro. Você não é obrigado a cadastrar uma chave para usar o Pix.
