# Não é preciso pagar para fazer portabilidade

A nova instituição (proponente) é responsável pela quitação da dívida e o cliente não precisa pagar para que a portabilidade seja efetivada. Mas, se o solicitante ainda não é cliente da instituição para onde quer transferir a dívida, ela pode cobrar tarifa de confecção de cadastro para início de relacionamento.
