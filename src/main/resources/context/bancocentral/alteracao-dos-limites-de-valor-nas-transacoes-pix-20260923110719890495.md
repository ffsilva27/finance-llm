# Alteração dos limites de valor nas transações Pix

As instituições participantes do Pix devem oferecer aos seus clientes pessoa física uma funcionalidade para alteração de limites no aplicativo utilizado para iniciar transações Pix. Esta funcionalidade deve permitir: solicitação de aumento e redução dos limites para transações Pix; solicitação de aumento e redução dos limites para transações relativas ao Pix Saque e Pix Troco; solicitação de aumento ou redução dos limites para transações relativas ao Pix Agendado; solicitação de aumento ou redução dos limites para transações relativas ao Pix Automático; cadastramento de contas ou usuários recebedores para estabelecer limites diários específicos. Se você quiser reduzir seus limites de Pix, inclusive para valor zero, o banco deve fazer a mudança de imediato. Se você quiser aumentar os limites, o banco pode aceitar ou não. Caso aceite, o novo limite será ajustado entre 24h e 48h após o pedido. Se você quiser aumentar o limite do Pix Automático, o banco pode aceitar ou não. Caso aceite, o novo limite será ajustado em até 8h. Para sua segurança, quando não for possível identificar a localização do dispositivo usado para fazer o Pix, o banco pode impor limites menores, até mesmo zero.
