# A conta em moeda estrangeira no Brasil pode ser multimoeda?

​As contas em moeda estrangeira mantidas no Brasil devem ser abertas para movimentação em apenas uma única moeda. Para movimentar recursos em diferentes moedas, será necessário abrir uma conta para cada moeda.
