# Extrapolação do resultado das reclamações procedentes

No cálculo do índice de reclamações é utilizada a quantidade extrapolada de reclamações procedentes. O quadro abaixo ilustra um exemplo: em determinado período, foram respondidas duas mil reclamações por uma instituição, das quais mil foram analisadas e dessas, trezentas foram consideradas procedentes. O Banco Central (BC) extrapola o resultado e são consideradas seiscentas reclamações procedentes naquele período.
