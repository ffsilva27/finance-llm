# O extrato apresenta informações de mais de uma instituição financeira?

​Caso o cliente possua ou tenha possuído contas em mais de uma instituição participante do Selic, as informações são consolidadas sob um único extrato, por CPF ou CNPJ, mas discriminando-se o saldo que o cliente possui em cada participante.
