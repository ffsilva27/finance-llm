# Devolução de valores de cota capital de cooperativa de crédito

Caso um dos valores a receber seja referente a cotas de capital de ex-participantes de cooperativas de crédito, essas instituições podem devolver o valor em uma única vez, pelo valor total ou parcelar a devolução desse valor. Se a devolução for parcelada, a instituição informará mensalmente ao Sistema de Valores a Receber apenas os valores referentes às parcelas vencidas até aquele mês. Você poderá consultar o sistema todo o mês para solicitar o valor ou pode procurar a cooperativa responsável pelo valor para buscar uma forma de receber os valores automaticamente.
