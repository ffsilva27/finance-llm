# Código ACH Routing Number

​ACH Routing Number não é um código regulado pelo Banco Central (BC). É um código utilizado para transferências eletrônicas de dinheiro nos Estados Unidos. A sigla ACH significa Automated Clearing House , uma rede de câmaras de compensação bancária coordenada pela NACHA. É por meio das ACHs que os bancos norte-americanos processam suas transferências interbancárias locais, similares às nossas TED, DOC e pagamento de boletos.
