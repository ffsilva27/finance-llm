# Como posso acessar a relação de instituições de pagamento autorizadas a funcionar?

​Você pode consultar a lista das IPs autorizadas a funcionar no site do Banco Central em: Relação de Instituições em Funcionamento no País (transferência de arquivos) . É possível também acessar de forma direta as informações sobre determinada IP em: Encontre uma instituição .
