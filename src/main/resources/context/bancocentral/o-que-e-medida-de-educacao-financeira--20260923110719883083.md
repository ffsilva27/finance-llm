# O que é medida de educação financeira 

​É uma ação que permite ao cidadão desenvolver capacidades e autoconfiança para gerenciar bem seus recursos financeiros (definição está no documento O que é Cidadania Financeira ?, publicado pelo Banco Central em novembro/2018).
