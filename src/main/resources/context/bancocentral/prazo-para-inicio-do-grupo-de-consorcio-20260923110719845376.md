# Prazo para início do grupo de consórcio

A administradora possui prazo de 90 dias para constituir o grupo no qual o consórcio fez a adesão. Se a administradora não aprovar a constituição do grupo nesse prazo, todos os valores pagos devem ser devolvidos aos consorciados, acrescidos dos rendimentos líquidos provenientes de sua aplicação financeira.
