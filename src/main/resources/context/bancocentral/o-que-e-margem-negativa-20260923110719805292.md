# O que é margem negativa?

A margem negativa é um cálculo feito todo mês com base nas informações dos contracheques dos meses anteriores. Como exemplo, vamos considerar 35% do seu salário, ou benefício, que pode ser usado para pagar as parcelas do consignado. Vamos supor um salário de 1.000 reais. Nesse caso, haveria 350 reais disponíveis por mês para pagar o consignado. Se esta margem estiver totalmente comprometida, você não poderá fazer novos empréstimos. Nesse caso, teremos margem zero. Se houver novos descontos obrigatórios, como pensão alimentícia, pensão judicial, ou um desconto indevido, a margem poderá se tornar negativa.
