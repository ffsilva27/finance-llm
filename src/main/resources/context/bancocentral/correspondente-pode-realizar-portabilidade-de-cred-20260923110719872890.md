# Correspondente pode realizar portabilidade de crédito

É possível contratar a portabilidade por meio de um correspondente bancário, desde que o correspondente seja contratado pela instituição financeira onde você possui atualmente o empréstimo ou pela instituição financeira para a qual você quer transferir essa operação de crédito.
