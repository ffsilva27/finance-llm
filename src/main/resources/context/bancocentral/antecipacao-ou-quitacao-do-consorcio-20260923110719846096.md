# Antecipação ou quitação do consórcio

O contrato deve definir: Para o consorciado contemplado, as condições para a antecipação de parcelas Se o consorciado não contemplado pode realizar antecipação de pagamentos e, em caso positivo, quais são as condições dessa antecipação. Importante! A antecipação de todas as parcelas vincendas não garante direito à contemplação imediata.
