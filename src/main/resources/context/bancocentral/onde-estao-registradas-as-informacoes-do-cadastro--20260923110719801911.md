# Onde estão registradas as informações do cadastro positivo 

​ As informações de clientes pessoa física e jurídica enviadas por empresas prestadoras de serviço continuado (como água, luz e telefone), empresas comerciais, bancos e demais instituições autorizadas pelo Banco Central (BC) são registradas nos cadastros administrados pelos gestores de banco de dados. Os gestores não precisam de autorização BC para atuar, mas devem solicitar registro no BC, caso pretendam registrar informações de crédito repassadas por bancos e demais instituições financeiras. Para saber quais os gestores de banco de dados registrados no BC, acesse a página Encontre uma instituição e filtre pelo segmento Gestor de banco de dados.
