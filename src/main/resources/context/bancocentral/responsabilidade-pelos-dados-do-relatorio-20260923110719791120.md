# Responsabilidade pelos dados do relatório

​O banco onde você contratou a operação de crédito é obrigado a informar os dados das dívidas acima de R$200,00 no Sistema de Informações de Créditos (SCR). Essas dívidas são exibidas no Relatório de Empréstimos e Financiamentos (SCR). Além disso, ele é responsável por todas as inclusões, correções, exclusões e registros especiais sobre a dívida.
