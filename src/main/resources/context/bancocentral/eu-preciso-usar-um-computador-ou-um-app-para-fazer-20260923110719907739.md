# Eu preciso usar um computador ou um app para fazer meu orçamento?

​De forma alguma! O orçamento pode ser feito em um caderno, uma folha de papel, com caneta ou lápis. Só não vale fazer os cálculos na cabeça, pois nosso cérebro costuma nos deixar na mão nessas horas. O importante é anotar os gastos, projetar o que ainda será gasto e os ganhos para poder saber para onde vai o dinheiro, se há sobras, ou se está faltando. Com essa informação em mãos é preciso elaborar um plano, com ações para que você alcance seus sonhos e objetivos. Mas se você puder e quiser usar um aplicativo gratuito ou pago ou uma planilha no computador, isso pode te ajudar a fazer os cálculos e guardar suas informações. Saiba mais em Módulo 2 do Caderno de Educação Financeira.
