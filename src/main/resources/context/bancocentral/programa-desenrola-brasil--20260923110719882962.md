# Programa Desenrola Brasil 

​ O Programa Desenrola Brasil é um programa de renegociação de créditos inadimplidos, criado pelo Governo Federal, com o objetivo de recuperar as condições de crédito de devedores que possuam dívidas. Esse programa é da responsabilidade do Ministério da Fazenda. Para mais informações sobre o Desenrola Brasil, consultar a página na internet Programa Desenrola Brasil .‎ Caso tenha problemas com o banco e não consiga resolvê-lo, você pode registrar uma reclamação na página da internet do Banco Central (BC),  seguindo: "Serviços > Cidadão > Fale conosco para dúvidas e reclamações ".
