# Previsão contratual para escolha de duas ou mais taxas de juros

​O sistema permite que apenas uma taxa de juros seja informada para cada período de pagamento. Se o contrato prevê múltiplas taxas de juros em determinado período, o declarante pode escolher qual taxa informar.
