# Limite de pagamento com moedas metálicas

​Pessoas físicas, comércio e empresas em geral são obrigadas a receber até 100 moedas de cada valor por compra. Dessas forma, elas não podem se recusar a recebê-las ou limitar o pagamento em cédulas. Os bancos também só são obrigados a receber pagamentos até 100 moedas de cada valor. Já para depósitos, não há limite.
