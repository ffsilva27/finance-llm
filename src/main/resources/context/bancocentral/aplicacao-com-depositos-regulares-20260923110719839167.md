# Aplicação com depósitos regulares

​Nesse cálculo é simulado o total de dinheiro que uma pessoa pode acumular ao fazer aplicações mensais de mesmo valor. Para realizar a simulação, é necessário preencher os campos a seguir: valor do depósito regular; quantidade de meses; e taxa de juros mensal. O resultado será calculado automaticamente pela calculadora do cidadão no campo "valor obtido ao final". Para realizar o cálculo, clique aqui no MeuBC . Para saber detalhes sobre a metodologia utilizada no cálculo, acesse o link "metodologia", disponível na página do cálculo.
