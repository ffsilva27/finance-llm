# Diferença entre Drex e Pix

O Pix é o meio de pagamento, operado pelo Banco Central, que permite transferências instantâneas. O Drex também contará com o serviço de pagamento para liquidar transações com ativos digitais, mas sua principal vantagem é a oferta, por meio de uma plataforma segura, de produtos ou serviços financeiros (crédito, investimento, seguros, serviços inteligentes etc.).
