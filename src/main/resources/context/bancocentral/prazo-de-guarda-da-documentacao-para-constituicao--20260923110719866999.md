# Prazo de guarda da documentação para constituição de mandatários no sistema 

​A documentação comprobatória das autorizações para constituição de mandatários deve ser mantida sob guarda das partes pelo prazo mínimo de 10 anos e deve ser enviada ao Banco Central, caso solicitada.
