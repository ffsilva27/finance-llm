# Arredondamento do total de reclamações procedentes extrapoladas e do índice de reclamações

Para simplificar, a quantidade de reclamações procedentes extrapoladas é arredondada sem casas decimais, já o índice final é arredondado para duas casas decimais. Esses dois valores são apresentados no Ranking para cada instituição ou conglomerado.
