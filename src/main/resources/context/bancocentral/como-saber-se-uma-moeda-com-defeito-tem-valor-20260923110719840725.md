# Como saber se uma moeda com defeito tem valor

​Se você tem uma moeda torta, perfurada, desfigurada ou com algum defeito danos e não sabe se ela pode ser usada para pagamento ou depósito pode pedir uma avaliação do Banco Central (BC). Para isso, entregue-a ao banco. Ele deve receber a moeda, fornecer recibo a você e informar sobre o resultado da análise do BC.
