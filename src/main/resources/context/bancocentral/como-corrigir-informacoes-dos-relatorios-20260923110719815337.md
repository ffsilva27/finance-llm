# Como corrigir informações dos relatórios

​Caso seja identificado algum erro ou seus dados estejam desatualizados, você deve solicitar a retificação junto à instituição (financeira ou participante) na qual a chave foi registrada. Se o problema não for resolvido, reclame em www.consumidor.gov.br ou pelo Fale Conosco do Banco Central.
