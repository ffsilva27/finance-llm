# Interoperabilidade entre arranjos

Quando existirem, os acordos de interoperabilidade entre arranjos devem prever a possibilidade de os usuários finais utilizarem uma única conta corrente ou de pagamento para realizar pagamentos para usuários de outros arranjos. Os contratos de interoperabilidade firmados por instituidores de arranjos de pagamento devem observar condições semelhantes – sejam elas técnicas ou negociais – para situações semelhantes. Não há regra que obrigue expressamente a interoperabilidade dos arranjos. Contudo, a interoperabilidade é um dos objetivos a serem perseguidos pelos arranjos, assim como a implementação de um modelo único de interoperabilidade.
