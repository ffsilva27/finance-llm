# Operações simuladas na Calculadora do Cidadão

aplicação com depósitos regulares: simula aplicações mensais de mesmo valor com uma taxa de juros, mostrando o valor final após um certo número de meses; financiamento com prestações fixas: calcula os pagamentos mensais fixos necessários para liquidar um valor financiado com uma taxa de juros ao longo de vários meses; valor futuro de capital: projeta o valor futuro de um montante atual com uma taxa de juros, mostrando o valor ao final de um período específico; e correção de valores: atualiza um valor usando diferentes índices, como a poupança, inflação, taxa Selic, taxa legal, entre outros.
