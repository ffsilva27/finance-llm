# Parcelamento de multa

​É possível solicitar o parcelamento da multa aplicada em processo sancionador em até 30 vezes, desde que o valor da parcela seja pelo menos R$ 1.000,00 para pessoas físicas ou R$ 5.000,00 para pessoas jurídicas. A solicitação de parcelamento deve ser apresentada pelo Protocolo Digital.
