# Não encontrei minhas operações crédito externo no  SCE-Crédito (antigo RDE-ROF)

As operações incluídas no SCE-Crédito (antigo RDE-ROF) e que não se enquadram nas novas regras de prestação obrigatória de informações ficaram marcadas como "dispensadas" e podem ser consultadas utilizando o filtro na tela de pesquisa. Além disso, é preciso verificar as permissões do usuário dentro do sistema, como formas de login e cadastro de mandatários.
