# Quando a duplicata escritural passará a ser obrigatória?

​A obrigatoriedade será implantada gradualmente, conforme cronograma definido pelo Banco Central. Inicialmente, as instituições financeiras serão obrigadas a conceder crédito com base exclusivamente em duplicatas escriturais para empresas de grande porte. Posteriormente, para as empresas de médio e pequeno porte, conforme referido cronograma.​
