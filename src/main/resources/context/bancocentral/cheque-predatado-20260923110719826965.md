# Cheque pré-datado

O cheque pré-datado é aquele em que o emissor informa uma data futura para pagamento ao beneficiário. O cheque é, por definição, uma ordem de pagamento à vista e, portando, pode ser descontado pelo beneficiário a qualquer momento, mesmo antes da data pré-definida. Caso o cheque seja apresentado antes da data definida e com isso o cliente se sinta prejudicado, recomendamos procurar o Procon do seu Estado ou Município ou o Poder Judiciário, para possível solicitação de indenização por dano moral.
