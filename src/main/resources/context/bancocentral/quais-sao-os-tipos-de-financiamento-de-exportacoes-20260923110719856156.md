# Quais são os tipos de financiamento de exportações por meio de operações de câmbio?

Podem-se destacar 3 formas possíveis de financiamento de exportações por meio de operações de câmbio: Recebimento antecipado dos valores decorrentes das exportações; Adiantamento sobre Contrato de Câmbio (ACC); Adiantamento sobre Cambiais Entregues (ACE)
