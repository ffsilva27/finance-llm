# As instituições financeiras podem pagar juros sobre o saldo das contas?

​A instituição financeira que mantém a conta no Brasil não pode remunerá-la. Porém, os recursos mantidos nessas contas podem ser investidos no mercado internacional, respeitadas as regras aplicáveis.
