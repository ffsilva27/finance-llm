# Quais são os tipos de conta de pagamento?

Existem duas modalidades de contas de pagamento: pré-paga, que se destina à execução de transações de pagamento realizadas com base em valores previamente aportados pelo cliente; pós-paga, que se destina à execução de transações de pagamento que independem do aporte prévio de recursos, como, por exemplo, os cartões de crédito.
