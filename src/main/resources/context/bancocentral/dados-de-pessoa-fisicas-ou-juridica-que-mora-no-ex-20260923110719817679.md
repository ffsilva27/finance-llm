# Dados de pessoa físicas ou jurídica que mora no exterior

Se você mora no exterior, mas possui conta ou bens, direitos e valores mantidos ou administrados por instituições financeiras no Brasil, poderá conferir essas informações no relatório. Mas se você tem vínculo apenas com uma filial no exterior de uma instituição financeira nacional, ele não estará registrado no relatório. O relatório abrange somente operações realizadas no Brasil.
