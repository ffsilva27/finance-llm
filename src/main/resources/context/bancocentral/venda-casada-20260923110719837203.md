# Venda casada

Venda casada é quando o banco obriga você a contratar um serviço para ter acesso a outro de seu interesse. Ela é proibida de acordo com o direito do consumidor. Atenção! Venda casada é diferente dos casos em que o banco oferece melhores condições em uma determinada operação se você contratar determinado produto ou serviço. O que ele não pode é somente oferecer um produto se você levar outro.
