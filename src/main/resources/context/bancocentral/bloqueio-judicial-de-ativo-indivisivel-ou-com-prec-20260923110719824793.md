# Bloqueio judicial de ativo indivisível ou com precificação de difícil definição

A ordem de bloqueio para ativo indivisível (como fundos e títulos cujo lote não pode ser fracionado) atinge o ativo em sua totalidade. Já para o ativo cuja precificação não possa ser aferida com base em informações confiáveis disponíveis publicamente, cabe ao banco participante bloquear todos os ativos do atingido mantidos no banco. Se você teve uma conta ou um valor bloqueado judicialmente, verifique o motivo no banco onde você possui a conta. Somente uma nova ordem judicial pode desbloquear. Essa nova ordem pode acontecer no processo de origem do bloqueio ou com uma nova ação judicial.
