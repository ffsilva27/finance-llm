# Cadastro de conta única para bloqueio

​ É possível aos réus/executados cadas trarem uma conta única para bloqueio. Verifique como fazer o requerimento em Conta única - Portal CNJ . Se você teve uma conta ou um valor bloqueado judicialmente, verifique o motivo no banco onde você possui a conta. Somente uma nova ordem judicial pode desbloquear. Essa nova ordem pode acontecer no processo de origem do bloqueio ou com uma nova ação judicial.
