# Lista de correspondentes 

Para saber a lista de correspondentes e os pontos de atendimento clique aqui . Você pode filtrar por banco e por município, além de consultar quais os serviços prestados pelos correspondentes. Você pode, ainda, pesquisar por um correspondente específico, para ver se ele é contratado por algum banco. O cadastramento dos correspondentes, bem como a divulgação da lista de correspondentes cadastrados, são de responsabilidade das instituições financeiras.
