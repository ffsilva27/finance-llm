# Uso do crédito do Pronaf

​De acordo com o MCR-01-10 , os créditos do Pronaf podem ser usados para: Custeio Investimento; Integralização de cotas-partes pelos beneficiários nas cooperativas de produção; Industrialização; Os créditos individuais, independentemente de quem sejam os beneficiários, devem ter como objetivo o desenvolvimento do estabelecimento rural como um todo.​ ​​
