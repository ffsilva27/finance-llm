# Quanto tempo demora para um cheque em moeda estrangeira ser "compensado" no exterior?

​O prazo para a cobrança do cheque no exterior varia de acordo com os procedimentos estabelecidos em cada país. O cliente deve obter essa informação com a instituição autorizada a operar no câmbio com a qual pretenda fazer a operação.
