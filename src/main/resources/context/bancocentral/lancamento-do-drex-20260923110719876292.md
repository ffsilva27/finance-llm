# Lançamento do Drex

Ainda não há uma data específica para o lançamento do Drex. Ele está em fase de testes em ambiente restrito, o Piloto Drex, iniciados em março de 2023. Com base nos resultados do Piloto, o Banco Central deverá incluir testes com a população no Piloto Drex. Mas, para que isso seja possível, o projeto e os participantes do mercado precisarão ter atingido o grau de maturidade adequado. Saiba mais sobre o Piloto Drex .
