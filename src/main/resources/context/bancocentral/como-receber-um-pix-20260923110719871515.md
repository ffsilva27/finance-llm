# Como receber um Pix

​Para receber um Pix, você pode: criar um QR Code e mostrá-lo a quem vai te pagar (tanto a imagem do QR Code ou o código dele); ou informar ao pagador a sua chave Pix, que pode ser CPF/CNPJ, e-mail, telefone celular ou chave aleatória. Para gerar um QR Code é preciso ter uma chave Pix cadastrada. É possível também informar os dados completos de sua conta ao pagador, caso você não tenha uma Chave Pix.
