# Atualizar dados do responsável e substituto responsável pela declaração

Para alteração ou atualização dos dados dos responsáveis pela declaração da pessoa jurídica, o declarante deve acessar a página na internet do Banco Central (BC), no link do Sistema do Censo , via Login Único na Conta gov.br . Na aba “Dados do responsável ou substituto responsável pela declaração" é possível atualizar, a qualquer momento, dados do responsável (nome, CPF, e-mail, telefone) ou dados de seu responsável substituto (nome, e-mail, telefone), clicando no botão "Salvar" e, em seguida, no botão “Confirmar", para que as alterações sejam gravadas. Para mais informações, consultar o Manual do Declarante , que possui todos os conteúdos necessários para o preenchimento da declaração.
