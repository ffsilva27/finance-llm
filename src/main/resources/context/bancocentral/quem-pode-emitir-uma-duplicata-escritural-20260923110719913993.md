# Quem pode emitir uma duplicata escritural?

​A duplicata escritural é emitida pelo fornecedor de bens ou serviços que possui um valor a receber decorrente de uma venda ou prestação de serviço realizada a prazo ao comprador ou adquirente. Para isso, ele precisará contratar um escriturador.​
