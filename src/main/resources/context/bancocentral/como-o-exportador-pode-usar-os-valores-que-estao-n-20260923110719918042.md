# Como o exportador pode usar os valores que estão na conta?

​Os recursos podem ser utilizados livremente. Exemplos: transferências para conta de mesma titularidade; transferências para contas de terceiros; pagamento de obrigações em geral no Brasil; ou pagamento de obrigações no exterior. Porém, se as transferências e pagamentos forem feitos em reais, será necessária uma operação de câmbio.
