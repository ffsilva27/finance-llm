# O que acontece quando uma duplicata é negociada ou utilizada como garantia?

​A operação é registrada nos sistemas eletrônicos. Isso permite identificar quem é o atual titular da duplicata e se ela está vinculada a alguma operação de crédito ou garantia. Após o cumprimento das obrigações do empréstimo, a garantia deve ser retirada, liberando a duplicata.
