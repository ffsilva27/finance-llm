# Informações de conta conjunta

​As informações que aparecem no relatório são apenas referentes ao CPF pesquisado e não mostram se o relacionamento trata de cotitularidade de contas. Para informações, entre em contato com os bancos com os quais você possui ou possuía relacionamento.
