# Quais os tipos de recebíveis de arranjo de pagamento?

​ Os recebíveis de arranjos de pagamento se subdividem em: recebíveis constituídos, decorrentes de transações comerciais já realizadas e de pagamento a liquidar; e recebíveis a constituir, decorrentes de transações de existência futura e montante desconhecido.
