# Alteração de dados cadastrais associados ao CPF ou ao CNPJ

​O Banco Central (BC) não é o órgão responsável pela base de dados associada ao CPF ou ao CNPJ. Dessa maneira, qualquer alteração cadastral na base do CPF ou CNPJ deve ser direcionada à Receita Federal do Brasil (RFB), órgão responsável pelo gerenciamento e armazenamento das correspondentes informações.
