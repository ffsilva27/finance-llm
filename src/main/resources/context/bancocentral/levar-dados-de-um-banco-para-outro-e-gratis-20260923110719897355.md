# Levar dados de um banco para outro é grátis

O compartilhamento de dados e de serviços por meio do Open Finance é gratuito. As instituições estão oferecendo aos clientes diversos serviços que usam os dados recebidos, como, por exemplo, aconselhamento financeiro. As instituições não têm cobrado por esses serviços, mas, eventualmente, elas poderiam cobrar tarifas. Vale lembrar que as instituições só podem cobrar qualquer tarifa quando: O serviço for contratado pelo consumidor; e Se estiver previsto na tabela de tarifas da instituição.​ Consulte as Perguntas e Respostas sobre Tarifas para saber mais sobre o assunto.
