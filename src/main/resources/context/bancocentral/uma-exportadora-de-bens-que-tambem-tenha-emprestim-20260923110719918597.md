# Uma exportadora de bens que também tenha empréstimo externo ou investimento estrangeiro pode utilizar uma única conta para todas as finalidades? 

É permitido o desembolso de recebimento antecipado de exportação diretamente na conta de exportador, ainda que haja necessidade de declaração no SCE-Crédito, uma vez que a operação subjacente se enquadra tanto como exportação como crédito externo. Nas demais operações de crédito externo e de investimento estrangeiro, depende da obrigatoriedade de declaração no SCE: se a dívida ou o investimento estiver sujeito à declaração no SCE-Crédito ou no SCE-IED, é necessária uma conta para cada finalidade; se não houver essa obrigação, a movimentação relacionada a essas operações pode ocorrer na conta de exportador, respeitadas as restrições aplicáveis aos créditos nessa conta. ​Também é possível pagar o crédito externo diretamente da conta do exportador, sem necessidade de transferência prévia para a conta específica.
