# Reclamação anônima contra instituições financeiras

Você pode reclamar contra instituições financeiras sem se identificar. Nesse caso, você não receberá uma resposta, mas sua reclamação ajudará o Banco Central (BC) a fiscalizar as instituições. Como fazer: Telefone: ligue 145 (dias úteis, das 8h às 18h) Internet: use a plataforma Fala.BR Correspondência: envie carta para o endereço do BC em Brasília (Deati/Divisão de Atendimento ao Cidadão | SBS Quadra 3 Bloco B, CEP 70074-900) Presencial: use a urna da Sala SIC no edifício-sede do BC, em Brasília O que você precisa saber: Use o anonimato para relatar problemas gerais (como a atuação ou conduta irregular de um banco). Para problemas pessoais (como cobranças indevidas) é necessário se identificar para que o banco possa te enviar uma resposta. Se as informações forem insuficientes para entender o problema, a reclamação anônima será cancelada. O BC pode usar esses dados internamente para ações de supervisão. Não é possível o registro de reclamações anônimas pelo canal de atendimento disponível em: “Serviços > Cidadãos > Fale conosco para dúvida e reclamação .​
