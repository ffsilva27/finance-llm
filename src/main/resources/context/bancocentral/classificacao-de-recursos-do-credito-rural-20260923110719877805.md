# Classificação de recursos do crédito rural

​Os recursos utilizados para o crédito rural podem ser considerados como controlados ou não controlados. Os controlados, que são utilizados financiamento de operações com as condições previamente definidas, como taxas de juros, limites e prazo, são os seguintes: Recursos obrigatórios; Recursos das Operações Oficiais de Crédito; Recursos de qualquer fonte destinados ao crédito rural; Recursos dos fundos constitucionais de financiamento regional; Recursos do Fundo de Defesa da Economia Cafeeira (Funcafé). Os demais recursos não indicados são classificados como não controlados.
