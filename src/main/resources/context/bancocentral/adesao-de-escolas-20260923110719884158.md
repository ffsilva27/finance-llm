# Adesão de escolas

A adesão de uma escola no programa deve ser realizada pelo(a) diretor(a) da escola. Para isso, precisa ter Conta gov.br, nível prata ou ouro, e se cadastrar. Quando um(a) diretor(a) de escola se cadastra na plataforma​ Aprender Valor, a escola passa a aderir automaticamente ao programa. A escola que aderiu não recebe recursos financeiros do Banco Central, mas pode participar de concursos e concorrer a prêmios. Além disso, passa a fazer parte da lista de escolas aderidas, no site do Aprender Valor. A escola que adere ao programa não fica obrigada a usar os recursos didáticos do Aprender Valor. Todos os recursos disponibilizados pelo programa são de uso opcional. Cada escola pode utilizar os conteúdos que lhe forem mais úteis para levar educação financeira para as salas de aula.
