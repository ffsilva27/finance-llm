# O extrato substitui os documentos fornecidos pela minha instituição financeira?

​O Extrato do Tesouro Direto e Selic​ é uma fonte oficial de consulta das posições registradas no sistema. Entretanto, para esclarecimentos sobre movimentações, operações específicas ou informações complementares, o cliente deve contatar a instituição financeira responsável pela conta de custódia.
