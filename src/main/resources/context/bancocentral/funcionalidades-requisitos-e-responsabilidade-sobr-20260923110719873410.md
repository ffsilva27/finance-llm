# Funcionalidades, requisitos e responsabilidade sobre o sistema eletrônico usado para compartilhamento de dados e informações sobre indícios de fraude

Funcionalidades mínimas: registro, alteração, exclusão e consulta de dados e informações sobre indícios de ocorrências ou de tentativas de fraude. Requisitos mínimos: acesso pleno das instituições e padrão único de comunicação que permita a execução de suas funcionalidades. Responsabilidade: a responsabilidade pela implementação de sistema eletrônico é das instituições obrigadas ao referido compartilhamento, envolvendo, portanto, a execução de todas as funções. Inclusive, elas deverão dar, mensalmente, conformidade no sistema de registro eletrônico.
