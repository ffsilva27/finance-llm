# Responsabilidade pelas informações prestadas no SCE-Crédito (antigo RDE-ROF)

​ A responsabilidade pela veracidade, legalidade e
fundamentação econômica das informações prestadas no SCE-Crédito (antigo
RDE-ROF) é exclusiva do devedor.
