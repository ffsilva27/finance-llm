# O que é Documento de Crédito (DOC)?

O DOC era um tipo de transferência financeira com limite de R$4.999,99. Essa operação não existe mais entre usuários Pessoa Física e Pessoa Jurídica. Pode existir apenas para operações entre instituições financeiras. Diferente da TED, o crédito na conta do beneficiário ocorria no dia útil seguinte à data de emissão, porém, o efeito financeiro na conta do cliente emissor, para determinados fins, podia ocorrer na mesma data da emissão, a critério da instituição recebedora. Além disso, cada instituição podia estabelecer um horário limite para emissão de DOC.
