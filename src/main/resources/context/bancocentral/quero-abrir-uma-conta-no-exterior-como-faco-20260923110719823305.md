# Quero abrir uma conta no exterior. Como faço?

​As normas brasileiras não se aplicam a contas abertas no exterior. Para
abrir uma conta em outro país, você precisa se informar sobre as regras do país
onde você deseja abri-la. Verifique também as normas para manutenção e
encerramento dessa conta no exterior.
