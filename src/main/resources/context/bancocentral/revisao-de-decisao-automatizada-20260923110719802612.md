# Revisão de decisão automatizada

O titular dos dados, ou seja, o cadastrado pessoa física ou jurídica no cadastro positivo, tem direito de solicitar a revisão de decisões tomadas unicamente com base em tratamento automatizado de dados pessoais que afetem seus interesses, incluídas as decisões destinadas a definir o seu perfil de crédito. Essa automatização de dados é realizada por sistemas que coletam e armazenam dados de clientes, conforme critérios e procedimentos estabelecidos pelos gestores dos bancos de dados.
