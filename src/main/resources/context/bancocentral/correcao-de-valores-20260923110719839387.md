# Correção de valores

Nesse cálculo é simulada a atualização de valores, usando índices de preços, TR, a remuneração da poupança, taxa Selic, CDI e Taxa Legal (TL). Atenção! A Calculadora é apenas um instrumento de auxílio ao cidadão e os valores calculados são apenas indicativos, de forma que não são de observância obrigatória na prática pelas instituições financeiras. Os cálculos são realizados a partir de informações fornecidas pelo usuário e devem ser considerados apenas como referência para situações reais e não como valores oficiais. Para realizar a simulação, é necessário preencher os campos a seguir: Selecionar o índice para a correção; data inicial; data final; e valor a ser corrigido. O resultado será calculado automaticamente pela ferramenta, conforme campo "dados calculados". Para realizar o cálculo, clique aqui . Para saber detalhes sobre a metodologia utilizada no cálculo, acesse o link "Metodologia", disponível na página de cada cálculo.
