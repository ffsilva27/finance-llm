# Arranjos de pagamento supervisionados pelo BC

O BC supervisiona todos os arranjos de pagamento que não se enquadrem nas condições previstas na regulação. Os arranjos supervisionados são considerados arranjos integrantes do Sistema de Pagamentos Brasileiro (SPB).
