# Existe uma forma simplificada de abertura de conta de pagamento?

Sim. É admitida a abertura de conta de pagamento com base em processo de qualificação simplificado, desde que estabelecidos limites adequados e compatíveis de saldo e de aportes de recursos para sua movimentação. Para mais informações, consulte sua instituição de pagamento.
