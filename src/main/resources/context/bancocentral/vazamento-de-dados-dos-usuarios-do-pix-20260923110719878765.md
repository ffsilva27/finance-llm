# Vazamento de dados dos usuários do Pix

Os participantes do Pix devem comunicar aos titulares de chaves Pix que sejam pessoas naturais a ocorrência de incidente de segurança com dados pessoais envolvendo banco de dados. Isso deve ocorrer mesmo que esse participante provedor da conta não seja o responsável pelo incidente e ainda que o incidente de segurança não resulte em risco ou dano relevante aos titulares.​​
