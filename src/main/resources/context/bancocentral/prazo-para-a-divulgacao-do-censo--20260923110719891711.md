# Prazo para a divulgação do Censo 

​Não há prazo definido para a divulgação. Após o período de recebimento das declarações, o Banco Central valida os dados obtidos, para depois elaborar e divulgar os quadros com os resultados, de forma agregada, preservando o sigilo de informações individuais. Para mais informações, consultar o Manual do Declarante , que possui todos os conteúdos necessários para o preenchimento da declaração.
