# Segurança do sistema de compartilhamento de dados e informações sobre indício de fraudes

​O BC definiu requisitos mínimos do sistema para garantir a segurança dos dados e informações registrados. Além disso, obriga as instituições a garantirem a confiabilidade, integridade, disponibilidade, segurança e pelo sigilo em relação aos dados e informações por elas registrados nesse sistema eletrônico. Em caso de incidentes (por exemplo, abrangendo o vazamento de informações), a instituição poderá ser responsabilizada pelo BC administrativamente.
