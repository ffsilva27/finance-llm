# Autorização para funcionamento das fintechs de crédito pelo BC 

​Para informações sobre os procedimentos para autorização para funcionamento de sociedade de crédito direto (SCD) ou sociedade de empréstimo entre pessoas (SEP), consultar as perguntas e respostas no Meu BC autorização para funcionamento . A relação das SEPs e SCDs autorizadas pode ser consultada em nossa página na internet seguindo: "Serviços > Cidadão > Encontre uma instituição ". (Segmento: sociedades de crédito direto ou sociedades de empréstimo entre pessoas).
