# Possuo uma conta fora do país e gostaria de utilizá-la para pagar uma obrigação no exterior. É possível?

​Sim. Pessoas físicas e jurídicas podem realizar essa operação. Como a movimentação
é feita exclusivamente usando contas no exterior e sem envolver outras partes
no país, não há operação de câmbio nesse caso.
