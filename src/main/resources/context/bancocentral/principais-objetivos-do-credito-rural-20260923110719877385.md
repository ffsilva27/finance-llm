# Principais objetivos do crédito rural

​Os principais objetivos são: Estimular os investimentos rurais; Favorecer o custo da produção e a comercialização de produtos agropecuários; Incentivar corretamente o sistema de produção, para aumentar o padrão de vida das populações rurais, defender o solo e proteger o meio ambiente; Possibilitar, pelo crédito fundiário, a compra e regularização de terras para grupos específicos; e Desenvolver atividades florestais e pesqueiras.
