# Dificuldades para prestar informações em nome de um terceiro

​ Caso tenha se deparado com a mensagem de erro "O usuário não está autorizado a realizar a ação desejada", informamos que, para incluir uma operação crédito externo em nome de terceiro, é necessário ser Mandatário com permissão para incluir novas operações em nome dele. A gestão de Mandatários pode ser realizada no sistema SCE-Crédito por: Instituições financeiras, desde que autorizadas formalmente pelo devedor conforme normativos vigentes; Outras pessoas jurídicas ou físicas que já constem como mandatário com permissão para incluir novas operações desse devedor; Pelo próprio devedor. Para mais detalhes sobre mandatários no sistema SCE-Crédito, consultar o capítulo 9 do manual do SCE-Crédito .
