# Como os dados são transmitidos de uma instituição para outra  

​Com a sua permissão para o compartilhamento de dados por meio do Open Finance, a instituição recebedora dos dados se conecta diretamente à instituição de origem das informações (transmissora: aquela com a qual você tem relacionamento, como uma conta) e acessa somente os dados autorizados por você. Para os serviços de pagamento, com a sua permissão, a instituição iniciadora do pagamento envia sua solicitação diretamente para a instituição onde está sua conta a ser debitada. Essa conexão direta é feita por meio de APIs (Application Programming Interface), que são padrões e protocolos de programação que permitem que os sistemas de diferentes instituições "conversem" entre si. Essas APIs do Open Finance são desenvolvidas com base em rigorosos critérios de segurança.​
