# Financiamento com prestações fixas

Nesse cálculo é simulado um financiamento com prestações fixas, utilizando o sistema francês de amortização, conhecido como tabela price . Para realizar a simulação, é necessário preencher os campos a seguir: quantidade de meses; taxa de juros mensal; e valor da prestação. O resultado será calculado automaticamente pela calculadora do cidadão no campo "valor financiado". A Calculadora utiliza capitalização mensal, e todas as prestações são compostas por "amortização" e "juros". Para realizar o cálculo, clique aqui no MeuBC . Para saber detalhes sobre a metodologia utilizada no cálculo, acesse o link "metodologia", disponível na página do cálculo.
