# Como saber qual código devo usar para classificar a finalidade da operação de câmbio?

​ O cliente da instituição autorizada a operar no mercado de câmbio indica a finalidade da operação de câmbio com uso dos códigos divulgados aqui . Em caso de dúvida, entre em contato com essa instituição que, conforme a Lei nº 14.286, de 2021, deve prestar orientação e suporte técnico para o cliente que necessitar de apoio para a correta classificação dessa finalidade.
