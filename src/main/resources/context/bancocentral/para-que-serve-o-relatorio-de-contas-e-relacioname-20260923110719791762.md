# Para que serve o Relatório de Contas e Relacionamentos (CCS)

O relatório serve, principalmente, para você: conferir em quais bancos possui conta, investimentos e outro tipo de relacionamento, verificar se seu CPF ou CNPJ foi usado indevidamente para abertura de conta fraudulenta, pesquisar contas e relacionamentos bancários de pessoa falecida para inventário.
