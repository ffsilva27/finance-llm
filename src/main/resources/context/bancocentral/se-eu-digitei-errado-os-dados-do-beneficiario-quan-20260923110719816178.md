# Se eu digitei errado os dados do beneficiário, quando o recurso é devolvido para minha conta?

​O recurso deve voltar para sua conta em até 60 (sessenta) minutos após liquidação interbancária, desde que a operação tenha sido feita dentro do horário de funcionamento do sistema de liquidação de transferência de fundos. Entretanto, a instituição para onde o recurso foi enviado pode estender esse prazo pelo tempo necessário para apurar indícios de irregularidade.
