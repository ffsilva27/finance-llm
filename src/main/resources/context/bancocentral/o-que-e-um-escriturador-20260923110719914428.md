# O que é um escriturador?

​Os escrituradores são entidades autorizadas pelo Banco Central a realizar a atividade de escrituração das duplicatas. O fornecedor poderá contratar um escriturador diretamente ou por intermédio de terceiros, como instituições financeiras.
