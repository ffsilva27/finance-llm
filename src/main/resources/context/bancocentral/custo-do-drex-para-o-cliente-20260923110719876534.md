# Custo do Drex para o cliente

Assim como as operações atuais, o cliente pagará o valor cobrado pela instituição pela oferta do produto ou serviço na Plataforma Drex (crédito, investimento, seguros, serviços inteligentes etc.). Mas, com um ambiente mais eficiente e que facilita a entrada de novas instituições, o Drex irá favorecer a oferta de produtos e serviços financeiros com custos menores aos praticados atualmente.
