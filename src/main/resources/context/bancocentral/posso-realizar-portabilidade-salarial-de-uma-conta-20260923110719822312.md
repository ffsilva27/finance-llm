# Posso realizar portabilidade salarial de uma conta de pagamento para outra conta?

​Não. O fato de receber o salário em uma conta de pagamento não a
torna uma conta-salário. Contudo, embora a portabilidade salarial não esteja garantida ao beneficiário,
nada impede ele faça transferências mensais para outra conta, sujeitas à cobrança de
tarifas. Saiba mais sobre conta-salário e portabilidade salarial aqui.
