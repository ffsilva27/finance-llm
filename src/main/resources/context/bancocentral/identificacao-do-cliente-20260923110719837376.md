# Identificação do cliente

O banco é responsável por coletar e validar as informações necessárias para identificar você antes de iniciar o relacionamento. Para isso, o banco define qual a documentação você precisa apresentar. Isso vale inclusive para o processo de abertura de contas, presencial ou digitalmente, já que não há uma lista definida de documentos necessários para sua identificação na abertura de conta. A instituição financeira pode aceitar qualquer documento de identificação original reconhecido pela lei brasileira para cadastro. A instituição ainda pode comparar as informações que possui com outras disponíveis em bancos de dados públicos ou privados. Pode também pedir documentos adicionais, de acordo com seu perfil de risco e com o tipo de serviço que você vai contratar. Se você autorizar, a instituição deve fornecer suas informações cadastrais a terceiros, inclusive a outras instituições financeiras. É importante que você comunique ao banco qualquer mudança em seus dados cadastrais, como endereço e telefone, para mantê-los sempre atualizados.
