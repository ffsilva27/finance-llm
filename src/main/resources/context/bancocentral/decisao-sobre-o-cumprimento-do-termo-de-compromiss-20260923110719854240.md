# Decisão sobre o cumprimento do Termo de Compromisso 

​Findo o prazo estabelecido no Termo de Compromisso (TC), o Banco Central (BC) deve declarar se as condições nele estabelecidas foram satisfatoriamente cumpridas pelo compromitente.
