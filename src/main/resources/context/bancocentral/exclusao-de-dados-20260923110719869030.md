# Exclusão de dados

​O sistema de Capitais Brasileiros no Exterior (CBE) não possui a funcionalidade "exclusão". Para casos que necessitem exclusão, o declarante deve preencher a declaração imputando 1 centavo em um ativo qualquer, por exemplo depósito. A declaração será aceita pelo sistema CBE e será tratada como uma exclusão.
