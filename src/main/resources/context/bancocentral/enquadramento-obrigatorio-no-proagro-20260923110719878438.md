# Enquadramento obrigatório no Proagro

​As operações de custeio agrícola de até R$270.000,00 são obrigatoriamente enquadradas no Proagro. A lavoura deverá estar dentro do Zoneamento Agrícola de Risco Climático - Zarc, financiado com participação de recursos controlados, observadas as condições definidas no programa.
