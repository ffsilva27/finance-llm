# Como proceder para receber antecipadamente os valores referentes às minhas exportações?

A operação no mercado de câmbio relativa a ingresso de recursos referentes a recebimento antecipado de exportação no Brasil é efetuada como qualquer outra operação realizada nesse mercado, observado que o recebimento com prazo de pagamento superior a 360 dias a partir de US$1 milhão está sujeito à prestação de informações ao Banco Central sobre capitais estrangeiros.
