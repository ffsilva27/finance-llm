# Autorregulação

​O Banco Central (BC) não estabelece requisitos ou parâmetros para fins de instituição de autorregulação pelas instituições supervisionadas ou por entidade associativa a elas vinculadas, assim como também não fiscaliza o cumprimento de autorregulação eventualmente instituída.
