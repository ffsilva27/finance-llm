# Cuidados na hora de contratar uma operação de crédito

​Você deve sempre olhar o Custo Efetivo Total (CET), que soma todos os encargos e as despesas das operações contratadas, ou seja, taxa de juros, tarifas, imposto e outros custos. As instituições devem informar a você o CET de cada operação de crédito oferecida para que possa comparar com outras propostas existentes. Quer saber mais sobre o CET? Calma que o BC te explica!
