# É possível transferir recursos entre contas de mesma titularidade?

​É permitido transferir recursos entre contas em
moeda estrangeira de mesma titularidade sem necessidade de operação de câmbio,
mesmo que tenham finalidades diferentes. Nesse caso, devem ser observadas as
regras da conta de destino, que, em alguns casos, podem impedir o recebimento
dessa transferência. Além disso, o uso dos recursos transferidos deve ser compatível com a finalidade da
conta receptora. Por exemplo, valores transferidos de uma conta de exportador para uma conta vinculada a crédito externo ou a investimento estrangeiro direto só podem ser usados para cumprir obrigações decorrentes dessas operações.​
