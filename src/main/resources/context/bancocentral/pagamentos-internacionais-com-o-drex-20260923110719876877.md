# Pagamentos internacionais com o Drex

​A prioridade é desenvolver a Plataforma Drex para o uso em transações nacionais. Porém, o Banco Central participa das discussões e acompanha testes de pagamentos internacionais com outras moedas digitais de bancos centrais.
