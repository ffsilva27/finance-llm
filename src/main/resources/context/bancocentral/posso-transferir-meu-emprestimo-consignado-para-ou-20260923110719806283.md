# Posso transferir meu empréstimo consignado para outro banco?

É possível fazer portabilidade de crédito consignado, ou seja, transferir a operação para outro banco que ofereça condições melhores. Contudo, a portabilidade de cartão de crédito não se aplica ao caso do cartão consignado. Saiba mais sobre portabilidade​ .
