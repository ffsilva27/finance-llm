# Quanto a pessoa jurídica paga para usar o Pix

​A pessoa jurídica pode ser tarifada nas seguintes situações: No envio de Pix (situações de transferência): se o recebedor for uma pessoa física e usar o Pix informando os dados da conta, chave ou iniciação de transação de pagamento; e se o recebedor for pessoa jurídica e usar Pix informando os dados da conta ou chave. No recebimento de Pix (situações de compra): se o pagador for pessoa física; se o pagador for pessoa jurídica e usar o serviço de iniciação, o Pix por QR Code, ou outra forma de iniciação associada ao Pix Cobrança; se tratar de um Pix Automático.​
