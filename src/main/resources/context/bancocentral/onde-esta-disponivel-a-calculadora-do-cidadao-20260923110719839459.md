# Onde está disponível a Calculadora do Cidadão

A Calculadora do Cidadão está disponível para download gratuito em dispositivos móveis, nas seguintes lojas: App Store Google Play Windows Phone Store Atenção! Não há versão disponível para instalação em computadores, mas apenas a versão web (online) na página do MeuBC .
