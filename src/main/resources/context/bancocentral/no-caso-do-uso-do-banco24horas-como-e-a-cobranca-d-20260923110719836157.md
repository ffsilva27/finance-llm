# No caso do uso do Banco24Horas, como é a cobrança de tarifas?

Os Banco24Horas são dispositivos eletrônicos administrados por empresa privada prestadora de serviço às instituições financeiras. Essas instalações não são consideradas dependências das instituições financeiras. Por isso, não é obrigatória a afixação nessas instalações das tabelas de tarifas de cada instituição conveniada. Mas para fins de cobrança de tarifas, o uso de terminal 24Horas tem o mesmo tratamento dos terminais próprios das instituições financeiras. Por exemplo: é vedada a cobrança pelo fornecimento de até quatro saques gratuitos, por mês, realizados em conta de depósitos à vista neste canal de atendimento, se não forem feitos saques em outros tipos de terminais.
