# Como o BC seleciona as reclamações que serão analisadas 

​O Banco Central (BC), com base em metodologia estatística, seleciona e analisa uma amostra relevante das reclamações respondidas pelas instituições reclamadas. A seleção das reclamações que serão analisadas é feita de forma totalmente aleatória e os critérios utilizados são os mesmos para todas as instituições. E as instituições não sabem quais reclamações serão analisadas pelo BC.
