# Migração de um financiamento em andamento para o SFH

​O financiamento que você já contratou e está pagando pode ser reenquadrado no SFH, desde que a operação esteja conforme com as condições definidas para o Sistema Financeiro da Habitação (SFH). Para fazer a migração, você deve negociar com o banco atual ou transferir a operação para outro banco. Em ambos os casos, será preciso fazer uma nova avaliação do valor do imóvel.
