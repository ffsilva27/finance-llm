# Quem fiscaliza os sistemas de duplicatas escriturais?

​O Banco Central é responsável por regular, autorizar e supervisionar as entidades que realizam a escrituração, o registro e o depósito centralizado das duplicatas escriturais, garantindo o cumprimento das normas aplicáveis.​
