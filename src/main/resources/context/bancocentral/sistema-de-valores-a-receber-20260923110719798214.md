# Sistema de Valores a Receber

O Sistema de Valores a Receber do Banco Central (BC)​ é uma plataforma que permite aos cidadãos e empresas consultarem se possuem dinheiro a receber em bancos e outras instituições fiscalizadas pelo BC e, em caso positivo, verifiquem como solicitá-lo. Não precisa pagar nada para consultar e solicitar os valores. O serviço do BC é 100% gratuito.
