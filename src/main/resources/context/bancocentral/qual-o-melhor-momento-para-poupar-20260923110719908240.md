# Qual o melhor momento para poupar?

​Todo mês, assim que você recebe seu salário. Chamamos isso de “pagar-se primeiro". Isso significa que você deve fazer seu planejamento mensal e prever quanto é possível economizar por mês. Caiu o salário na conta? Já separa e investe para aquele tão desejado sonho. Se você não fizer isso, as chances de você gastar e não sobrar nada no fim do mês são grandes. ​
