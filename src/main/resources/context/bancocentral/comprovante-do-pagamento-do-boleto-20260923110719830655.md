# Comprovante do pagamento do boleto

​Segundo a convenção dos boletos de pagamento, a instituição recebedora deve imprimir os dados de autenticação do recebimento no boleto de pagamento físico ou emitir comprovante de pagamento do boleto recebido. Para maiores informações sobre a convenção entre instituições do Sistema Financeiro Nacional (SFN), referente aos boletos de pagamento, consultar a página da Febraban .
