# Quando envio recursos para o exterior ou recebo recursos do exterior, o dinheiro passa pelo Banco Central?

Não. As operações de câmbio são realizadas diretamente entre o cliente e a instituição autorizada a operar no mercado de câmbio. As transferências internacionais de valores são efetuadas entre referida instituição e a parte localizada no exterior, não havendo nenhum trânsito de moeda pelo Banco Central.
