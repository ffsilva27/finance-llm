# Quem pode incluir e excluir mandatário no sistema

Instituições Financeiras, desde que autorizadas formalmente pelo devedor conforme normativos vigentes; Outras Pessoas Jurídicas ou Físicas que já constem como Mandatárias desse devedor no sistema; O Próprio Devedor.
