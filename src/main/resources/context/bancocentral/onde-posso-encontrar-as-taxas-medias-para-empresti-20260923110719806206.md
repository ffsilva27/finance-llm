# Onde posso encontrar as taxas médias para empréstimos consignados?

Você pode consultar essas taxas no site do Banco Central. Para consultar as taxas percentuais anuais, use os códigos abaixo. Você consegue acessar dados desde 2011. 20744 - Trabalhadores do setor privado; 20745 - Trabalhadores do setor público; 20746 - Aposentados e pensionistas do INSS; 20747 - Crédito pessoal consignado total.
