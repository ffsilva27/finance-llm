# Quando quero transferir recursos para uma conta no mesmo banco ou instituição, os valores são creditados no mesmo dia?

​Sim. A transferência entre contas da mesma instituição é conhecida no mercado como b o ok transfer . O valor transferido normalmente é creditado imediatamente na conta do credor, independentemente se a transferência ocorre em finais de semana ou em dias não úteis, no entanto, a instituição pode estabelecer critérios para isso.
