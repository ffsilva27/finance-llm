# Documento Financeiro 90390

MOSCOW, Feb 7 (Reuters) - Russia’s top lender Sberbank said on Wednesday it would provide 7.3 billion roubles ($128.53 million) in project financing for a housing project by Glavstroy. Glavstroy is part of Russian aluminium tycoon Oleg Deripaska’s industrial group Basic Element (BasEl). $1 = 56.7979 roubles Reporting by Maria Kiselyova; Editing by Polina Ivanova
